# Kasulikud veebilehti ja ressursse

## Arendusriistad

### Koodiredaktorid
- [Visual Studio Code](https://code.visualstudio.com/) - Tasuta ja võimas koodiredaktor
- [Sublime Text](https://www.sublimetext.com/) - Kiire ja elegantne tekstiredaktor
- [Vim](https://www.vim.org/) - Klassikaline konsooliterminaliredaktor

### Git ja versioonihaldus
- [GitHub](https://github.com/) - Koodi hosting ja koostöö platvorm
- [GitLab](https://gitlab.com/) - Alternatiiv GitHubile
- [Bitbucket](https://bitbucket.org/) - Git ja Mercurial hoidla
