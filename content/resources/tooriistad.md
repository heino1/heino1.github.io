# Soovitatud tööriistad arendajatele

## Käsurea tööriistad

### Paketihaldur
- **npm** - Node.js pakettide haldur
- **yarn** - Alternatiiv npm-ile
- **pip** - Python pakettide haldur
- **composer** - PHP pakettide haldur

### Abivahendid
- **curl** - Andmete edastamine URL-ide kaudu
- **wget** - Failide allalaadimine
- **jq** - JSON töötlemine käsureal
- **grep** - Teksti otsing failidest

## Versioonihaldus

```bash
# Git põhikäsud
git init          # Alusta uut repositooriumit
git clone         # Kopeeri repositoorium
git add           # Lisa failid staging'sse
git commit        # Salvesta muudatused
git push          # Saada muudatused serverisse
git pull          # Hangi muudatused serverist
```

## Arenduskeskkonnad

### IDE-d
- **IntelliJ IDEA** - Java ja muud JVM keeled
- **PyCharm** - Python arendus
- **WebStorm** - JavaScript ja veebi arendus
- **Visual Studio** - .NET arendus

### Kergemad redaktorid
- **VS Code** - Universaalne, väga populaarne
- **Atom** - GitHubi tekstiredaktor
- **Notepad++** - Windows'i tekstiredaktor

## Testimise tööriistad

- **Jest** - JavaScript testimise raamistik
- **pytest** - Python testimise raamistik
- **JUnit** - Java testimise raamistik
- **Selenium** - Veebi automaattestimine

## Koodi kvaliteedi tööriistad

- **ESLint** - JavaScript koodi kontrollimine
- **Prettier** - Koodi vormindamine
- **Black** - Python koodi vormindamine
- **SonarQube** - Koodi kvaliteedi analüüs

## Konteinerid ja virtualisatsioon

- **Docker** - Konteinerite haldus
- **Kubernetes** - Konteinerite orkestratsioon
- **VirtualBox** - Virtuaalmasinad
- **Vagrant** - Arenduskeskkonna haldus

## Andmebaasid

### SQL andmebaasid
- **PostgreSQL** - Võimas avatud lähtekoodiga andmebaas
- **MySQL** - Populaarne relatsiooniline andmebaas
- **SQLite** - Kerge andmebaas

### NoSQL andmebaasid
- **MongoDB** - Dokumentide andmebaas
- **Redis** - In-memory andmebaas
- **Elasticsearch** - Otsinguandmebaas

Need tööriistad moodustavad arendaja töölaua aluse.
